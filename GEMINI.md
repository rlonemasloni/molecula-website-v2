# Шпаргалка проекта MOLECULA

## Стек и запуск
- **Стек**: React 19, TypeScript, Vite, Tailwind CSS v4, Framer Motion, Radix UI / Shadcn.
- **Команда dev-сервера**: `npm run dev`
- **Порт и адрес**: `3000` (http://localhost:3000)

## Правила работы
1. **Точечный фокус**: Перед любой правкой UI сначала смотри пути в этом файле и открывай ТОЛЬКО целевой файл, не сканируя весь проект.
2. **Без лишних билдов**: После правок не запускай `npm run build` без прямой просьбы — изменения проверяются на живом dev-сервере с HMR.
3. **Поддержание карты**: В конце каждой задачи, если добавился новый файл или компонент, молча обновляй карту путей в `GEMINI.md`.
